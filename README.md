# Exam Dashboard

## Dashboard Preview

![Dashboard](IMG_1.png)

## Overview

This project is a dashboard for analyzing mock exam data.

The dashboard was developed as part of a university Project-Based Learning (PBL) course. It processes exam data extracted from PDF files and visualizes the results for easier analysis.

## Technologies

* Python
* Pandas
* Streamlit

## Features

* Extract data from PDF files
* Preprocess and clean exam data
* Visualize exam results
* Support score analysis and comparison

## Project Structure

* App_streamlit.py : Streamlit dashboard
* PDF_to_CSV.py : PDF data extraction
* Preprocess_to_Facts.py : Data preprocessing
* Rename.py : Data formatting utilities
